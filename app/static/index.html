CI/CD Pipeline & Webhook Integration

Integrate ShieldCI into any CI/CD runner, pull request gate, or trigger audits via webhooks and CLI anytime.

GitHub Actions Workflow 

name: ShieldCI Exposure Gate
on: [push, pull_request]
jobs:
  security-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run ShieldCI Exposure Scan
        run: |
          python -m app.cli --path . --fail-on HIGH --max-pes 60 --sarif results.sarif
      - name: Upload SARIF to GitHub Security
        uses: github/codeql-action/upload-sarif@v3
        if: always()
        with:
          sarif_file: results.sarif

CLI Universal Commands 

# Audit any remote Git repository directly
python -m app.cli --url https://github.com/org/repo --sarif out.sarif

# Audit local directory with strict threshold
python -m app.cli --path ./sample_vulnerable_repo --fail-on CRITICAL --max-pes 40

# View recent scan history in terminal
python -m app.cli --history

Instant Webhook Trigger Endpoint

Add this Webhook URL to GitHub or GitLab repository settings to trigger automatic scans on every push:

POST http://<your-host>:8000/api/webhook/github
Content-Type: application/json

# Or trigger on-demand scan for any Git repo via cURL:
curl -X POST http://127.0.0.1:8000/api/scan \
  -H "Content-Type: application/json" \
  -d '{"repo_url": "https://github.com/octocat/Hello-World", "fail_on_severity": "HIGH", "max_allowed_pes": 60}'
