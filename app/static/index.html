CI/CD Pipeline & Multi-Vector CLI

Integrate ShieldCI into any CI/CD runner, audit live websites or databases via CLI, and trigger automated scans via webhooks anytime.

CLI Universal Commands 

# 1. Audit any live Website / API
python -m app.cli --web https://example.com --sarif web.sarif

# 2. Audit any Database (URI or host:port)
python -m app.cli --db postgresql://localhost:5432/db --sarif db.sarif
python -m app.cli --db redis://127.0.0.1:6379

# 3. Audit any remote Git repository
python -m app.cli --url https://github.com/org/repo --sarif repo.sarif

# 4. View recent audit history across all assets
python -m app.cli --history

GitHub Actions Quality Gate 

name: ShieldCI Posture Gate
on: [push, pull_request]
jobs:
  security-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run ShieldCI Exposure Scan
        run: |
          python -m app.cli --path . --fail-on HIGH --max-pes 60 --sarif results.sarif
      - name: Upload SARIF to GitHub Security
        uses: github/codeql-action/upload-sarif@v3
        if: always()
        with:
          sarif_file: results.sarif

Direct REST API Endpoints 

# Audit a Website:
curl -X POST "http://127.0.0.1:8000/api/scan/website?url=https://example.com"

# Audit a Database:
curl -X POST "http://127.0.0.1:8000/api/scan/database?target=redis://127.0.0.1:6379"

# Audit a Git Repo:
curl -X POST http://127.0.0.1:8000/api/scan -H "Content-Type: application/json" \
  -d '{"repo_url": "https://github.com/octocat/Hello-World"}'
